# Contributing

Start with a question or bench report issue. Include the affected guide section, hardware identity, source revision and observations. Attach close photos with legible pin labels and an overview showing both endpoints.

Use pull requests for documentation and firmware changes. Explain the reason, evidence and validation. Keep the preserved firmware baseline intact and place proposed revisions in separately named sketch folders.

Distinguish source findings, historical reports, current bench results and hypotheses. Close a wiring question only when its specific endpoints and electrical conditions are established. Link the resolving issue from the updated guide.

Publish project-relevant excerpts and reviewed media. Check photos and logs for unrelated personal information and credentials before attaching them.
